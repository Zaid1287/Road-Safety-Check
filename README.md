**Overveiw
This project is a simulation tool that helps detect circular routes (cycles) in a city’s road network. It’s designed for civil infrastructure departments to evaluate whether a road layout contains unnecessary or potentially risky loops.
By modeling the road map as an undirected graph, this program identifies cycles using a graph traversal algorithm like DFS (Depth-First Search).

**Features
•	Graph Input: Add junctions and roads using user input.
•	Adjacency List: Build and display the road network efficiently.
•	Cycle Detection: Detect cycles using DFS traversal.
•	Result Output: Clearly states whether a cycle exists.
•	Clean Exit: All dynamic memory is freed properly before exit.

**Technologies Used
•	Language: C
•	Concepts: Graph Theory, DFS, Adjacency List, Memory Management

**Use Cases**
•	Civil engineering project simulations
•	Urban road design validation
•	Teaching aid for data structures and graph algorithms
•	Help city planners ensure safer and more efficient road networks.
•	Identify redundant routes that could be optimized or removed.
•	Serve as an educational tool to demonstrate graph cycle detection in real-world scenarios.
